Why This Route Exists

Fallback Directional Sprites

These remain the safe movement art even when a class-specific walk sheet has not been cleared for use.

BootScene keeps the directional fallback images loaded separately from the generated class walk sheets.

Candidate Walk Rows

Generated row attempts appear here before they replace runtime sprites. Use this area to judge the new art and animation directly.

These candidates are not installed in the game. They are isolated so rejected art can be reviewed without corrupting the playable runtime sheet.

Generated Class Walk Sheets

Each card overlays visible cell bounds on the full atlas and exposes every runtime crop as a separate inspectable cell, plus live walk loop previews for motion QA. A sheet is not accepted unless it contains the required contact/down/passing/high stride poses for its declared format.

`r0-c0` means row 0, column 0 within that sheet. Click a cell to zoom it and verify the crop coordinates. Watch the movement loops and reject extreme-only foot cycles. Row directions come from the same runtime geometry used by BootScene.
This route is intended for visual debugging, not browsing. If a sheet is missing, the page should make that failure obvious immediately.

Generated Class Attack Sheets

Runtime attack sheets use the same native 64px grid as movement, with one row per facing direction and eight frames per strike.

Battle animations read from this directory. Missing attack sheets should show here before they silently degrade to the old lunge-only fallback.

Other Sprite Assets

Battle Backgrounds

Pre-rendered Gemini scenes blitted behind combatants (issue #258). Each committed PNG is 800x600 with a 1600x1200 @2x companion on disk. Missing tiles render as a red card — run python3 scripts/generate_battle_backgrounds.py to fill them in.
