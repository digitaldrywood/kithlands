Expected Geometry

Directionals: 128x128 PNG
Walk sheets: 512x512 PNG
Walk cells: 4 rows x 4 columns at 128x128 each

Reason This Exists

Generated walk sheets are stored in `client/public/sprites/walk/`, but the runtime should only enable them after row and cell inspection passes. This page keeps that inspection on the main Vite dev server instead of relying on stale ad-hoc URLs.

Fallback Directional Sprites

These are the current fallback movement assets. If animated walk sheets are disabled, these are the sprites the client can safely use for directionally correct movement.

`BootScene` currently loads these as plain images, independent of any class walk-sheet enablement.

Generated Class Walk Sheets

Every card shows the raw sheet and all 16 sliced cells. Use this to verify row order, stance consistency, and bad frame mixes before enabling a class in movement runtime code.

`r0-c0` means row 0, column 0 within the 4x4 sheet. Compare against the fallback directional references above.
Missing images should be obvious here. The previous page silently requested files like `walk_down_0.png` that no longer exist.
