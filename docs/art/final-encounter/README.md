# Bellbound Regent

Original Kithlands final campaign boss. One static transparent monster image,
created with the built-in OpenAI imagegen tool on 2026-09-04. No runtime image
service is required. Finale-only Bell Sentinels reuse the existing original golem art under their
own stable content ID. Their stats match the previously sampled guards. No character animation or generic enemy AI changes.

Source: `bellbound-regent-source.png`. Runtime export:
`client/public/sprites/monsters/bellbound_regent.png`, fitted to 256 pixels and
padded by four transparent pixels. Runtime lookup lives in
`shared/monster_sprites.json`; content identity is `bellbound_regent`.

Prompt: Create a single original pixel-art RPG final boss asset named the
Bellbound Regent for Kithlands. A formidable enchanted bronze bell automaton
with a broad flared bell-shaped lower body, indigo-and-brass layered armor, a
crown of three tuning forks, two massive articulated arms, and a bright turquoise
cracked resonant core visible at the chest. Face a little to the right, as an
enemy on the left facing player heroes on the right. Full body, freestanding,
no ground, no background, no shadow, no text or border. Transparent RGBA
background is essential. Detailed and readable classic hand-painted pixel art,
strong dark outline, limited rich amber brass/indigo/teal palette, crisp pixel
clusters and highlights. Heroic and suitable for children; no gore, skulls,
horror or recognizable copyrighted character. One creature only, centered in
a square canvas with safe empty margin, calm battle-ready pose, all silhouette
visible. This is a static monster sprite, not an animation sheet. Save as PNG.

The source was inspected before export. Actual in-game desktop and phone
acceptance is recorded separately with the final encounter proof.
