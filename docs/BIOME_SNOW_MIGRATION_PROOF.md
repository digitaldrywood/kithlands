# Snow pocket cleanup and save migration

PR #339, branch `codex/battle-grounding-walk-lag`; follows `ae924ef`.

The world generator could produce individual snow tiles in meadow after roads and landmark clearings. The new server pass identifies connected snow regions after those operations. Regions smaller than twelve tiles join adjacent hill terrain where present, otherwise grass; larger regions remain snow. This changes the authoritative terrain and therefore local encounter terrain, while keeping both old and new tiles traversable. It is a limited correction, not a complete biome or landscape redesign. The remaining Cadott snow/highland island, repeated forest and sparse terrain still need an authored composition pass.

Historical pre-footbridge, pre-public-trail and public-trail generators retain their old output for exact checkpoint signature recognition. Existing resource placement versions use their original historical map as an anchor. New adventures use a new placement version. Loading still validates the checkpoint against the current map; unrelated signatures are not trusted. The migration test uses a fixture whose actual signature changes, harvests a site, loads twice, and compares position, all resource states, materials and absolute deadlines. Four public-trail and four earlier fingerprints remain pinned.

The renderer now gives snow a slightly higher blend priority than hill, making their boundary use the existing meadow feathering. Grass–snow and hill–snow planning both have unit checks. A first isolated test failed at login because the disposable database had not been migrated; the retry was run after setup. An earlier candidate failed a flawed assumption that snow must border grass. A separate count established a remaining 17-tile snow region. See tracker for those rejected-run details.
