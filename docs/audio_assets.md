## Lyria 3 Prompts

Prompts stored in `scripts/generate_music.py`. Each prompt specifies:
- Instrument palette (synth orchestral for SNES feel)
- Tempo and key
- Mood and energy level
- Loop-friendliness
- "No vocals" instruction
- Duration target
